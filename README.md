# 🚀 Back-End + Front-End API Integration with React

A full-stack project focused on communication between a backend API and a React frontend application.

The main goal of this project is to practice consuming REST APIs, handling data dynamically, and building an interactive user interface connected to a backend service.

---

## 📌 About the Project

This application demonstrates the integration between **Front-End and Back-End**, where the React interface consumes data provided by an API.

The project explores important concepts such as:

* API requests and responses
* Data fetching and rendering
* Component-based architecture
* Front-End and Back-End communication
* Dynamic user interfaces

---

## ✨ Features

* Consume data from a REST API
* Display dynamic information from the backend
* Reusable React components
* Responsive user interface
* Data management between client and server

---

## 🛠️ Technologies Used

### Front-End

* React.js

## 🔄 How It Works

1. The backend provides data through API endpoints.
2. The React application sends HTTP requests to the API.
3. The received data is processed and displayed through React components.
4. The user interacts with a dynamic interface connected to the backend.

## 🚀 How to Run the Project

### 1. Clone the repository:

```bash
git clone https://github.com/amandacarolinedev/Back-End-Front-End-Consumo-de-API-React.git
```

### 2. Navigate to the project folder:

```bash
cd Back-End-Front-End-Consumo-de-API-React
```

### 3. Install Front-End dependencies:

```bash
cd frontend
npm install
```

### 4. Start the Front-End:

```bash
npm start
```

### 5. Install Back-End dependencies:

Open another terminal:

```bash
cd backend
npm install
```

### 6. Start the Back-End:

```bash
npm run dev
```
